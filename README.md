## What I'm Building

### Online IDE

A browser-based development environment inspired by modern IDEs.

**Stack:** React · TypeScript · Vite · Node.js · Express · Prisma · PostgreSQL · WebSockets · Monaco Editor

```text
                    Online IDE
                        │
        ┌───────────────┼────────────────┐
        │               │                │
     Editor          Projects         Terminal
        │               │                │
     Monaco         File Tree        Commands
        │               │                │
        └───────────────┼────────────────┘
                        │
                    WebSocket
                        │
                     Backend
                        │
                 ┌──────┴──────┐
                 │             │
              Prisma       PostgreSQL
```

Current features:

* Monaco code editor
* Project management
* File/folder management
* File rename and deletion
* Database-backed projects
* Code execution
* Terminal interface
* WebSocket communication
* HTML preview
* Authentication
* Authorization

### Authentication & Authorization System

A security-focused backend exploring production authentication patterns.

**Stack:** Spring Boot · Spring Security · MongoDB · Redis · JWT · OAuth 2.0

Implemented:

* JWT access & refresh tokens
* Google OAuth
* Password authentication
* OTP verification
* Redis-based OTP storage
* Rate limiting
* Session management
* Role-based authorization
* CORS configuration
* Secure API design
